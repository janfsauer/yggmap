nodes

One node component, many states. Only ever one focused node — the node itself grows, its border goes ink-heavy, its shadow deepens. Multi-selection uses calm ink dashes.

ghost hints

Quiet gray placeholders around the focused node, showing where a key would create something — orange lives only on the keycap. They fade in steps as the user proves they know the shortcut, down to a faint whisper — never fully gone (a vanished hint reads as a bug). On mobile the tappable variant keeps the marker affordance.

connectors

Drawn by sketch.js: a jittered bezier plus a faint offset “pencil echo”. Ghost links are marker-dashed; hovering a node makes its branch hot.

keycaps & hint strips

The hint strip is contextual — its content follows what the user can do right now.

chrome

Everything that isn’t the map. Deliberately little of it.

context menu

Right-click on a node. Every item shows its keyboard route — the menu teaches its own obsolescence.

shortcuts panel

toast & marquee

Feedback stays quiet and always offers the keyboard way back.

empty canvas

The first thing a new user sees. No modal, no tour — the canvas itself asks the question.
